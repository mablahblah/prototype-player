# Prototype Player

This was created as an experiment with Claude Code, to play prototypes from prototyping tools I no longer have access to, and to embed those prototypes in my portfolio: [mablahblah.com/c/ghproto](https://mablahblah.com/c/ghproto).

- **Principle protos** - embeddable HTML prototypes, generated automatically from `.prd` files.
- **ProtoPie protos** - hand-converted prototypes, iterated with Claude Code from shared ProtoPie prototype links.
